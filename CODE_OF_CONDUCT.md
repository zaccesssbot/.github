# Code of Conduct

This is a personal automation account. Interactions on its repositories, in issues, discussions and comments, should be:

- Respectful and constructive
- On topic and relevant to the repository
- Free of spam, harassment or hate speech

A violation results in removal and blocking from the repository.

> [!NOTE]
> To report a concern, reach the owner privately at contact@isaacadjei.me or through the [contact page](https://isaacadjei.me/contact).

## The full code

The full code of conduct, the Contributor Covenant that the owner adopts in full, is in [zaccesss/code-of-conduct](https://github.com/zaccesss/code-of-conduct) and on [the website](https://isaacadjei.me/code-of-conduct). A repository with its own code of conduct takes precedence over this one.
