# Security Policy

> Public version of this policy: https://isaacadjei.me/security-policy

## Reporting a Vulnerability

If you discover a security vulnerability in a repository owned by this account, please **do not** open a public issue or pull request.

Report it privately to: **contact@isaacadjei.me**

Please include:
- A description of the vulnerability
- Steps to reproduce
- Potential impact

Expect a response within 72 hours.

## Scope

- Repositories owned directly by this account
- Automation this account runs on behalf of [@zaccesss](https://github.com/zaccesss)

## Out of Scope

- Forked repositories: report the issue to the upstream project instead
- Third party services (GitHub itself included): report those to the respective provider
